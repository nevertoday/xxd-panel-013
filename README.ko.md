> 가로 티켓 한 장 · 74/26 분할 · 치유 수채화 · 아이보리 여백 · 현지화 정보 스텁

XXD Panel 013는 Codex와 호환 에이전트를 위한 이미지 생성 Skill입니다. 정체성, 실루엣, 자세와 기억을 성립시키는 필수 환경을 보존하고, 그 관계를 고립된 사물 그림이 아니라 중앙에 떠 있는 한 장의 가로 수채화 티켓으로 요약합니다.

티켓 내부는 약 74/26의 좌대우소 구조입니다. 왼쪽은 원본을 고명도·저중채도의 인접색 2–4개로 부드럽게 번역하고, 오른쪽은 대상 언어의 정보 필드, 번호와 절제된 원형 도장 하나로 정돈합니다. 두꺼운 무광 수채화지, 섬세한 가장자리, 거의 보이지 않는 접촉 그림자와 넓은 아이보리 여백이 소중히 보관한 여행 스케치 티켓의 감촉을 만듭니다.

## 왜 013이 필요한가요

일반적인 ‘수채화 엽서’는 화면 가득한 범용 풍경, 고립된 사물, 더러운 빈티지 필터 또는 가짜 좌표와 소인을 붙인 쇼핑몰 템플릿으로 쉽게 무너집니다.

013은 순서를 뒤집습니다.

```text
주제와 필수 환경 고정 → 원본 고유 단서 최소 세 개 보존 → 중앙의 가로 티켓 한 장으로 요약 → 내부를 약 74/26의 그림과 스텁으로 분할 → 인접 치유색 2–4개로 수채화 번역 → 주제는 조금 선명하게, 환경은 자연스럽게 약화 → 현지화 필드, 원형 도장, 절취선을 하나의 그리드에 정렬
```

무관한 사진으로 바꿔도 수채화 주제, 필수 환경, 팔레트, 필드 의미, 도장 관계와 문구가 거의 그대로 성립한다면 013가 아닙니다.

## 013의 시각적 원칙

- **주제와 필수 환경:** 최소 세 가지 고유 단서로 정체성, 자세, 크기, 위치, 랜드마크와 공간 관계를 보존합니다.
- **가로 티켓 한 장:** 넓은 아이보리 여백 중앙에 두며 반복, 콜라주, 화면 채우기를 하지 않습니다.
- **약 74/26:** 왼쪽 수채화 면이 확실히 크고, 오른쪽 정보 스텁은 정확한 세로 절취선 하나로 나뉩니다.
- **치유 수채화:** 원본의 고명도·저중채도 인접색 2–4개, 종이 흰색, 번짐, 건습 변화와 소량의 안료 입자를 남깁니다.
- **절제된 위계:** 주제는 조금 선명하고 원경과 보조 환경은 자연스럽게 약해지며 사실적 조명과 복잡한 세부를 피합니다.
- **소장품 종이감:** 두꺼운 무광 수채화지, 섬세한 데클 또는 톱니 가장자리, 아주 옅은 자연 접촉 그림자만 사용합니다.
- **정보 그리드:** 현지화 필드, 번호, 짧은 선, 점열과 원형 도장 하나를 같은 왼쪽선, 기준선, 간격에 맞추며 사실을 꾸며 내지 않습니다.

## 네 가지 출력, 하나의 수채화 소장 티켓 논리

네 가지 모드는 하나만 또는 여러 개를 함께 선택할 수 있습니다. `1`, `1+3`, `1、2、4`, `전체`라고 답하면 Skill이 중복을 제거하고 1→4 순서로 실행합니다. 각 모드는 별도 작업 폴더에 독립적으로 출력되며 한 장의 모음 이미지로 합치지 않습니다. `전체`는 원본 한 장당 PNG 7개(일반 모드 각 1개＋배경화면 4개)를 만듭니다. 크기는 모드별로 표시해 같은 답변에서 지정할 수 있고, 지정하지 않은 일반 모드는 원본에 맞춥니다. 문구는 기본적으로 선택한 모드가 공유하며 모드별 지정도 가능합니다.

| 모드 | 크기 규칙 | 결과물 |
| --- | --- | --- |
| `top-bottom` | 원본 적응형 | 위에는 전체 원본, 아래에는 013 수채화 소장 티켓. 두 패널이 원본 크기를 유지하며 정확히 50/50 |
| `left-right` | 원본 적응형 | 왼쪽에는 전체 원본, 오른쪽에는 013 수채화 소장 티켓. 두 패널이 원본 크기를 유지하며 정확히 50/50 |
| `design-only` | 원본 적응형 | 원본 사진은 보이지 않고 변환 디자인만 표시. 원본 비율과 크기 유지 |
| `wallpaper-pack` | 기기별 네 가지 크기 | 휴대전화, iPad, 데스크톱, 어린이용 스마트워치 PNG 개별 출력 |

정확한 사용자 픽셀 > 지정 비율 또는 용도 > 일반 모드의 원본 적응형 순서입니다. 원본 `013.md`의 3:4는 초기 창작 캔버스일 뿐 현재 Skill의 숨은 기본값이 아닙니다.

짝을 이루는 모드의 사진은 절제된 색 보정과 필요한 환경 확장만 적용해 사실성을 지킵니다. 디자인 단독과 배경화면은 사진을 근거로 사용하지만 원본을 보여 주지 않습니다.

### 배경화면 세트: 연결형 또는 독립형

배경화면에는 숨은 기본 크기가 없습니다. 일반 프리셋은 휴대전화 `1440×3200`, iPad `2048×2732`, 데스크톱 `3840×2160`, 스마트워치 `1024×1024`이며 기기별 사용자 지정 크기도 가능합니다.

- **연결형 세트(권장):** 먼저 iPad 기준 작품을 생성하고 승인합니다. 나머지 세 기기는 원본 사진＋동일한 기준 작품을 참조해 각 화면에 맞게 새로 구성합니다.
- **독립형 네 작품:** 각 기기는 원본 사진만 참조하며 티켓 크기, 바깥 여백, 수채화 구도, 치유 팔레트, 필드 구성과 도장 관계를 각각 탐색합니다.

연결형은 크롭이 아닙니다. 네 장 모두 따로 생성하고 구성하며 검수하고, iPad→휴대전화→데스크톱→스마트워치 순으로 참조를 이어 붙이지 않습니다.

## 문구는 정보 스텁 안의 조용한 기록입니다

생성 전에 자동 문구, 사용자 지정 문구, 무문자 출력 중 하나를 선택합니다. 문구가 있으면 대상 언어나 지역도 지정합니다.

자동 문구는 사진에서 보이거나 근거가 있는 주제, 순간, 상태, 관계 또는 감정에서 극히 짧은 제목을 만들고, 정말 필요한 필드만 선택합니다.

DATE, PLACE, SUBJECT, MOMENT, FIELD, NO.는 필드 논리의 예일 뿐 영어 고정값이 아닙니다. 필드명과 값 모두 대상 언어로 현지화합니다. 날짜, 장소, 좌표, 경로, 티켓 번호와 여행 사건은 사용자 제공이나 신뢰할 수 있는 근거가 필요하며, 비여행 주제는 사물, 상태, 프로젝트, 장, 계절, 관계 또는 감정 기록으로 바꿉니다.

사용자가 완성 문구를 주면 그대로 유지합니다. 방향이나 수정 가능한 초안일 때만 대상 독자, 목적, 필수 단어, 어조, 함의를 보존하며 다듬습니다.

언어는 명령문의 언어가 아니라 의도한 독자를 따릅니다.

```text
목표 시장 또는 독자 > 지정한 결과물 언어 > 방향 지시 언어; 모두 불분명하면 생성 전에 질문
```

일본판은 자연스러운 현대 일본어를, 한국 독자용은 자연스러운 현대 한국어와 정확한 띄어쓰기를, 영국판은 영국 영어를 사용합니다. 아랍어판은 기본적으로 자연스러운 현대 표준 아랍어와 올바른 오른쪽에서 왼쪽으로 흐르는 구성을 사용합니다. 외모, 옷, 풍경, 간판으로 국적을 추측하지 않으며 가짜 외국어 문자를 쓰지 않습니다.

## 정확한 기하는 코드가, 작품은 이미지 생성이 맡습니다

이미지 모델이 원본에 묶인 주제—환경 수채화, 티켓 한 장, 74/26 분할, 종이 가장자리, 절취선, 정보 그리드, 원형 도장과 현지화 문자를 만듭니다. `scripts/compose_panel.py`는 캔버스 계획, 정확한 50/50 래스터 합성, 최종 크기와 검수만 수행하며 프로그램 그림으로 결과물을 위조하지 않습니다.

```bash
python3 scripts/compose_panel.py --plan --layout top-bottom --source photo.png
python3 scripts/compose_panel.py --plan --layout left-right --size 2560x1440
python3 scripts/compose_panel.py --audit result.png --layout design-only --size 2048x2048
```

정확한 상하 캔버스는 전체 높이, 좌우 캔버스는 전체 너비가 짝수여야 합니다. 요청 픽셀을 몰래 변경하지 않습니다.

## 경계와 신뢰

- 각 사진은 독립된 작업 안에서만 사용하며 다른 입력, 과거 결과, 예시의 피사체, 색, 문구, 구도를 빌리지 않습니다.
- 호출할 때마다 새 작업 폴더를 만들고 원본과 조건이 같아도 새로 생성합니다.
- 결과물은 PNG 비트맵이며 SVG, HTML, Canvas, 프로그램 드로잉 대체물이 아닙니다.
- 설정된 비트맵 브리지는 정제된 상태만 출력하며 공급자, 엔드포인트, 헤더, 인증 정보, 프롬프트, 응답 본문을 노출하지 않습니다.
- 선택한 일반 모드마다 파일 1개를 반환하고, `wallpaper-pack`을 선택하면 독립 배경화면 4개를 추가합니다. `전체`는 원본 한 장당 PNG 7개를 네 개의 동급 모드 폴더에 저장하며 모음 이미지로 합치지 않습니다.

로컬 합성에는 Python 3와 Pillow가 필요합니다. 안전한 비트맵 브리지는 Python 3.11 이상의 `tomllib`을 사용합니다. 이미지 생성에는 내장 래스터 기능이 있는 호스트 에이전트 또는 이미 설정된 호환 경로가 필요합니다.
