# XXD Panel 013｜治愈水彩收藏票根生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

### 模型优先级与凭据

- **优先使用 GPT Image 2。** 当 GPT Image 2 通过当前内置图像工具或已配置兼容通道可用时，先用它完成本提示词要求的高保真垫图／编辑与完整画布生成。
- 也支持 Seedance 5.0 Pro、Nano Banana Pro（Gemini Image Pro）、Nano Banana 2（Gemini Image Flash）或其他兼容位图模型，但只有实际通道具备原图保真、整张成品画幅、目标语言文字，以及连贯壁纸所需多图参考能力时才可使用。
- 备用模型只替换生图通道，不得改变本提示词的模式、画幅、原图可见性、文案、语言、壁纸关系或“完整画布优先、拼合仅兜底”的执行逻辑。不能满足硬性条件时不得静默降级。
- 没有合适通道时，请用户启用生图工具或提供 API Key。用户主动提供凭据可以用于当前任务，但不得在回复、日志或提示词中回显、展示、记录或泄露其值；未经明确要求不得长期保存或修改全局路由配置。
- 按实际生图能力判断可用性，不因某个工具、供应商名称或单一环境变量缺失就武断判定全部通道不可用。

只处理当前任务明确提供的这一张源照片。先锁定主体、必要环境、轮廓、姿态、结构、位置、尺度与叙事关系，至少保留三个源图专属识别线索。不要借用旧成品、样张或其他输入的地点、主体、配色、票据信息、文案和构图。

## 主体与必要环境

找出源图中最值得记住的一组“主体—环境”关系，并把它概括进一张横向水彩票根。人物保留姿态、朝向、衣着体块与关系距离；动物保留身体节奏和所处环境；植物保留生长走势与光；建筑保留天际线和关键开口；物件与交通工具保留功能轮廓、尺度和位置；景观保留源图专属的地平线、地形、道路、水体或空气。

不要把主体从决定其身份和意义的环境中孤立出来。次要细节可以减弱，但必须保留能让人一眼对应原图的必要背景与空间关系。禁止添加通用地标、机场代码、路线、旅游故事和原图没有的道具。

## 单张票体与 74/26 几何

在象牙白或暖白大留白中只悬置一张横向票体，保持唯一焦点，不放多张票、不做拼贴、不让票体填满画布。卡纸厚实、哑光、带水彩纸纹，边缘细密锯齿或自然毛边，只有极轻微自然接触投影；禁止污渍、烧边、裂纹和戏剧化做旧。

票体内部严格左大右小：左侧约 74% 是水彩画面，右侧约 26% 是信息票根。中间用一条精准的竖向虚线、齿孔或撕票线分隔，不得漂移成均分、斜切或不规则手账叠层。上下边距统一，图像、文字、印章、编号、短线和点列服从同一隐性网格与基线。

## 高明度治愈水彩

从源图中选择最清新、最有生命力的颜色，统一转译为 2–4 个相近的高明度、低至中等饱和度自然综合色。鼠尾草绿、雾蓝、浅青灰、奶油黄、暖沙、淡陶土只是可能方向，不是固定色卡。仅在源图支持时用极少量暖色对比点亮主体。

笔触清楚而轻薄，保留纸白、柔和晕染、透明叠色、干湿变化与少量色素颗粒。主体稍清晰，远景和次要环境自然减弱；层次来自水彩浓淡与边缘控制，不来自写实光影、复杂细节、数字渐变和厚重不透明填色。

禁止灰蒙、发黄、重褐、浓艳撞色、廉价复古滤镜、电影光效、油画厚涂、照片级写实、塑料质感和 3D。

## 右侧信息票根与文字

服从已锁定的自动文案、用户准确文案或无文字模式，以及目标语言／地区。用户准确文案逐字保留；无文字时不生成任何字段、编号、印章字样或伪文字。

自动文案生成一个极短、源图绑定的标题或时刻短句，并只选择有意义的少量字段。可使用目标语言中自然对应的 DATE、PLACE、SUBJECT、MOMENT、FIELD、NO.，但字段名与字段值都必须本地化，不得默认保留英语。

日期、地点、坐标、路线、票号、出处和旅行事件必须由用户提供、源图明确显示或可靠确认，不得虚构。非城市或非旅行题材应把无关地点字段改为对象、状态、项目、章节、季节、关系或情绪记录；构图索引必须明显是索引而不是伪造事实。

所有字段沿统一左边线、基线和间距排列，字号层级清楚、留白充足。只使用一枚克制的圆形印章，可与分割线或底部网格轻微交叠，但不能遮挡有效信息。禁止信息漂浮、装饰邮戳墙、旅游口号、粗大标题和软件界面感。

## 模式与验收


硬性验收：只有一张居中横向票体和大面积象牙白留白；至少三个源图线索与必要主体—环境关系；厚实哑光水彩纸、细密边缘和极轻投影；内部约 74/26 左大右小并由精准竖向齿孔线分隔；左侧 2–4 个相近治愈色、轻薄水彩、主体稍清楚、环境柔化；右侧本地化字段、统一左边线和基线、一个圆章、无伪造事实；无孤立物件、满版水彩、脏旧、黄褐、浓艳撞色、松散排版、复杂装饰、写实插画、电商模板、照片残片或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas 或后期文字覆盖伪造成品。
